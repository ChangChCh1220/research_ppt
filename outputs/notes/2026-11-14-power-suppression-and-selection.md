# 專題研究筆記：功率抑制映射機制與約束式選模

- **論文出處**：張喬筑碩士論文《光達輔助弱監督之四維雷達可靠度估計與功率抑制》（指導教授：莊子毅 博士，NYCU）
- **主要章節**：第三章 3.5 節、3.7 節，第四章 4.3 節
- **主題定位**：連續軟式保留、硬式門檻歸零、Version08 平台式映射、綜合選模目標 $J$ 與 29,736 種組合搜尋之取捨反思

## 一、功率抑制核心定位與輸出約束

本研究處理的是稀疏雷達表示中的**線性功率分配問題**：
- **格式不變性**：維持每幀原始 150,000 點資料，每點之三維座標 $(x,y,z)$、點序、都卜勒值 $v$ 及浮點資料型態（float32/float64）完全不變。
- **純原位調整**：僅將原始非負線性反射功率 $P_i$ 替換為修改後功率 $P'_i$。
- **架構保護**：不進行物理刪點，確保下游偵測器（RTNH）的 $0.4\text{ m}$ 體素化網格占據結構與稀疏卷積神經網路的拓撲特徵不發生非預期塌陷。

## 二、三種功率抑制映射函數（論文圖 3-2）

### 2.1 連續軟式加權映射（式 3-4）
$$P'_i = P_i \left[ \alpha + (1 - \alpha) s_i^\gamma \right]$$
- $\alpha \in [0, 1]$ 為最低保留倍率，$\gamma > 0$ 控制曲線凸凹性。
- **固定基準 W065**：使用 $\alpha = 0.65, \gamma = 1$。
  - 當可靠度分數 $s_i = 0$（最低分）時，仍保留 $65\%$ 的線性功率；
  - 當 $s_i = 1$（滿分）時，保留 $100\%$ 的原始功率。
- **優缺點**：平滑連續，無階躍邊界，不會完全清除微弱訊號；但高分可信車體點仍遭受微幅折損，低分噪聲亦無法徹底壓制。

### 2.2 硬式門檻歸零映射（式 3-5）
$$P'_i = P_i \times \mathbb{I}(s_i \ge \tau)$$
- 當分數低於門檻 $\tau$ 時，功率直接歸零；其餘點維持 100% 原功率。
- **評估門檻空間**：$\tau \in \{0.1, 0.2, 0.35, 0.5, 0.7, 0.9\}$。
- **本質釐清**：此處為「硬式歸零」而非「硬式刪點」，資料列依然保留在記憶體中。

### 2.3 Version08 待驗證平台式映射曲線（Platform Curve）
$$w(s) = \alpha + (1 - \alpha)\text{clip}\left(\frac{s}{\tau}, 0, 1\right)$$
- **設計哲學**：分開控制「可信點無損保留」與「低分背景抑制」。
  - 當分數 $s \ge \tau$（達到較低可信門檻，例如 $\tau=0.2$）時，直接賦予 $100\%$ 滿額功率；
  - 當 $s < \tau$ 時，線性過渡至非零底線 $\alpha$（如 $\alpha=0.3$）。
- 徹底消除連續軟式抑制對可信車體點的能量折損，同時對背景進行階梯式壓制。

## 三、約束式選模目標 $J$ 與全域搜尋空間

### 3.1 綜合選模目標函數 $J$（式 3-8）
$$J = 0.30 T_{\text{GT}} + 0.20 T_{\text{LiDAR}} + 0.20 Q_{\text{positive}} + 0.30 Q_{\text{far-truck}}$$
- $T_{\text{GT}}$：每幀 ROI 內分數前 Top5% 點中，落在真實 3D 物件框內的比例（衡量目標區域集中度）。
- $T_{\text{LiDAR}}$：Top5% 點中距離 LiDAR 不超過 $0.5\text{ m}$ 的比例（衡量幾何支持度）。
- $Q_{\text{positive}}$：可靠正例群組修改後功率總和除以原始功率總和（正例保留率）。
- $Q_{\text{far-truck}}$：60–80 公尺具有 LiDAR 支持之大型車物件幀宏平均功率（避免少數強回波主導）。

### 3.2 三大不可違背之篩選約束（相對基準 W065）
1. **可靠正例功率保留降幅**：$\Delta Q_{\text{positive}} \le 0.01$（不超過 1%）。
2. **背景代理功率增加上限**：$\Delta Q_{\text{background}} \le 0.01$（不超過 1%）。
3. **幾何比例變化**：兩項幾何比例的平均變化不得為負。

### 3.3 搜尋空間規模
- 64 個搜尋維度，去重後共 354 組模型設定。
- 每個設定重複 3 個隨機種子，共 1,062 個訓練模型。
- 每個模型橫向比較 28 種功率策略（原始 1 種、軟式 21 種、硬式 6 種），完整計畫涵蓋 **29,736 筆紀錄**。

## 四、聯合比較成果與深刻取捨（論文表 4-2）

在已完成三種子評估的設定中，模型與功率策略聯合排名：
- **第一名**：焦點損失（正例係數 0.75）+ **硬式門檻 0.1**
  - 綜合目標 $J = \mathbf{0.6900}$；正例功率保留率 $99.99\%$；遠距大車保留率 $99.31\%$；
  - **背景功率殘留**：高達 **$73.62\%$**。
- **第二名**：品質焦點損失（QFL）+ **硬式門檻 0.1**
  - 綜合目標 $J = 0.6887$；背景功率殘留 $68.99\%$。

### 4.1 取捨與局限深度反思
1. **硬式低門檻的表面優勢**：硬式門檻 0.1 採取了極度保守的策略，將絕大多數中高分點全數保留，因而推高了正例與遠距大車的功率保留率。
2. **背景抑制的妥協**：高達 73.6% 的背景功率殘留，意味著背景雜波並未被充分濾除。
3. **指標權重的偏向**：選模目標 $J$ 為遠距大車設定了 0.3 的高權重，使得背景抑制能力相近的候選，只要大車保留率稍高便能大幅領先。
4. **科研態度**：我們在論文中客觀指出，不能僅看 $J$ 的排名就斷定該組合對下游 RTNH 最優，必須交由下游偵測器進行最終裁決。
