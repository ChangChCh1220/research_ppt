# Raw Sources（原始資料層）

本目錄存放所有未經修改的原始研究資料，是整個知識庫的 **Source of Truth（唯一真實來源）**。

> [!CAUTION] 不可變原則（Immutable）
> LLM Agent **只可讀取**本目錄的檔案，**不可修改、重新命名或刪除**這裡的任何原始資料。

## 子目錄說明

- `papers/`：論文檔案（PDF、從 arXiv 轉換的 Markdown、論文原文筆記）
- `articles/`：技術部落格、官方文件、使用 Obsidian Web Clipper 擷取的文章
- `notes/`：個人研究靈感、實驗紀錄原稿、會議/課堂逐字稿
- `assets/`：本地下載的圖片與圖表附件（建議在 Obsidian 中將預設附件路徑設為 `raw/assets/`）
